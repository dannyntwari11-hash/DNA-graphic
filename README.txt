DNA GRAPHICS — FINAL WEBSITE

GitHub Pages upload:
1. Upload ALL files and the assets folder to the ROOT of your repository.
2. Make sure index.html is directly in the repository root.
3. In GitHub: Settings → Pages → Deploy from branch → main → / (root).
4. Wait for the Pages deployment to finish.

All website images are packaged locally in assets/ so the portfolio does not depend on third-party image URLs.
The supplied DNA logo has been cleaned for website use and is stored as assets/logo.png.
